# Smart Dorm Environment Monitor

A Python-based dorm room monitoring system that tracks temperature and humidity.

## Current Features

- Generates simulated temperature readings
- Generates simulated humidity readings
- Records the date and time
- Evaluates whether the room is comfortable
- Warns about hot, cold, humid, or dry conditions
